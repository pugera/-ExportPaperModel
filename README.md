# Fabric Pattern 1.1 — Blender用の布型紙・縫製プレビューアドオン

ぬいぐるみ・着ぐるみなどの表面メッシュを、手動シームと布の種類を尊重して平面へ展開します。展開した布を3D形状に戻すときの伸び・縮みを三角形ごとに計算し、指定値を超える領域には自動でダーツまたは追加シームを入れます。

## インストール

動作確認環境は **Windows / Blender 5.1.2**。Blender 4.2以降を対象としていますが、他のバージョンは未検証です。追加のPythonライブラリーは不要です。

1. `fabric_pattern_addon.zip` を任意の場所に置きます。解凍する必要はありません。
2. Blenderの **編集 → プリファレンス → アドオン → メニュー → ディスクからインストール** でZIPを選び、有効にします。
3. 3Dビューポートで **N** キーを押し、**Fabric Pattern** タブを開きます。

## 入力と目印

Blenderでメッシュとして読み込める形式が入力になります。OBJ・FBX・glTF・STLなどを標準のインポート機能で読み込み、対象オブジェクトを選択します。

**目印を保存するファイルには `.blend` を推奨します。** 一般的な交換形式ではBlenderのシームや独自エッジ属性が失われる場合があるため、インポート後に目印を付けてください。

- **必ず切りたい場所:** 編集モードで辺を選択し、標準の「シームをマーク」を実行します。
- **独自の目印:** パネルの「選択辺を型紙の切れ目にする」も使えます。標準シームに加え、辺の整数属性 `fp_cut=1` が保存されます。解除には同じパネルの解除ボタンを使ってください。標準シームだけを解除しても独自の目印は残ります。
- **布の種類が変わる場所:** 面を選択し、別々のマテリアルを割り当てます。「マテリアル境界を切る」を有効にすると、その境界が切れ目になります。テクスチャ画像の色境界だけでは布の種類を判定しません。
- 布の表面を表す1枚のメッシュを使用します。厚み付きソリッドの内外面を同時に入力すると、内外の両方が型紙になります。
- モディファイアが有効な場合は、複製したオブジェクトに適用してから実行します。シェイプキーはベースメッシュの座標が対象です。ポーズやシェイプキーの変形結果を使う場合も、複製をメッシュ化してから実行してください。

## 型紙を作る

1. 対象を選択して、許容する伸び・縮みをそれぞれ％で設定します。
2. 実寸を設定します。「シーンの単位を使う」が有効な場合、1単位の長さは `1000 × シーンの単位スケール` mmです。例えば単位スケール1なら1単位＝1mです。無効にするとmmを直接入力できます。オブジェクトの拡大縮小は計算に反映されます。
3. 縫い代とPNG解像度、出力先を設定します。
4. **型紙を作成・出力** を押します。計算中はBlenderのUIが一時的に応答しなくなる場合があります。進捗はシステムコンソールに出ます。
5. 結果の **PASS / DRAFT** と `report.json` を確認します。

元のオブジェクトと元のUVは保持されます。追加コレクションに3D作業コピーと2D配置メッシュが生成され、どちらも初期状態では非表示です。アウトライナーから表示できます。3D作業コピーには追加したシームと `FabricPattern` UVが残ります。UVは正方形へ正規化されており、その正方形の実寸はオブジェクトの `fabric_uv_square_mm` に保存されます。

出力は実行ごとに別の日時フォルダーを作成します。

## 出力ファイル

| ファイル | 内容 |
| --- | --- |
| `layout.svg` | 全パーツを配置した実寸のベクター画像。幅・高さの単位はmmです。 |
| `overview.png` | 番号順の一覧。各パーツを個別の倍率で枠に収めた確認用画像です。印刷用ではありません。 |
| `pieces/P001.svg` など | 各パーツの実寸ベクター画像。印刷用の原本に適しています。 |
| `pieces/P001.png` など | 各パーツのPNG。実寸を示す解像度情報を格納しています。 |
| `seam_pairs.csv` | 縫い合わせ番号、相手のパーツ、両側の縫い線長、長さの差。 |
| `piece_materials.csv` | 型紙の布番号（M001など）とマテリアル名の対応。 |
| `report.json` | 設定、各パーツの最大伸縮、面の対応、重なり検証、反復履歴。 |
| `PRINT_README.txt` | 印刷と線の読み方の説明。 |

**濃い外周が裁断線、青緑が縫い線、グレーの帯が縫い代** です。SVGの縫い線は破線、PNGでは青緑の実線です。対応する `S###` を縫い合わせます。短い線は対応する合印です。合印の位置は元の3D辺の長さから決めるため、両側で同じ場所に対応します。

`D###` は同じパーツ内で合わさる切れ目です。先端が閉じたダーツは楔部分を布として残し、両脚の縫い線を合わせ、オレンジ線に沿って折ります。特殊な内部切れ目で通常のダーツ形状を作れなかったものは、CSVで `type=seam` と記録されます。縫い代は丸い角の外側オフセットとして描きます。細い凹部、ダーツ口、交差する縫い代は裁断前に確認してください。

印刷時は「用紙に合わせる」を解除し、**実際のサイズ／100％** で印刷してください。必ず **100mmの確認線** を定規で測ってください。PNGの実寸情報を無視するアプリではSVGを使用します。各PNGが設定した最大画素数を超える場合は、実寸を維持したまま解像度を下げ、実際のdpiをレポートへ記録します。A4分割印刷は、ベクター画像を扱える印刷ソフトで行ってください。

## 伸縮判定と自動分割

1. 元の面との対応を記録して作業コピーを三角形化します。
2. 手動シーム・独自マーカー・マテリアル境界を固定します。
3. BlenderのAngle Based展開を実行します。
4. 各三角形について、**平らな布 → 3D表面** の2×2変形行列の特異値を求めます。値が1.05なら5％の伸び、0.95なら5％の縮みです。辺だけの長さ比較では検出できない斜め方向の変形も対象になります。
5. 各パーツの実寸倍率を、最大の許容量使用率が最小になるように調整します。伸び・縮みの指定が異なる場合もそれぞれ反映します。
6. 許容量を超えるパーツでは、高い歪みのある内部から境界への経路をダーツ候補として試します。改善が十分でない候補は取り消し、面の接続に沿って領域を分割します。
7. 全パーツが条件を満たすか、パーツ数・反復回数の上限に達するまで繰り返します。合格候補のパーツは三角形の反転と面積を持つ重なりも検査します。

**PASS** は、三角形化した入力表面に対する、指定された幾何学的な伸縮・反転・重なり条件を満たしたことを示します。許容誤差は伸縮率で0.0001パーセントポイントです。

**DRAFT** は未達のパーツが残った結果です。失敗したパーツIDと値をレポートで確認し、手動シーム、上限、許容量を調整してください。自動で許容量を緩めることはありません。元から指定されている手動シームによるパーツ数が上限を超える場合は、その手動指定を維持します。

## 扱う範囲

型紙生成は、方向に依存しない伸縮許容量で、メッシュ表面の形を平面化します。1.1ではBlenderのクロスによる縫製プレビューを追加しました。布目方向による物性差、実測した繊維の応答、縫い代や折り代の厚み、綿詰めの圧力、ゆとり量、実際の縫製手順は再現していません。

## 縫った結果をクロスでプレビューする（1.1）

1. 型紙を作成した後、元のオブジェクトまたは生成された3D作業コピーを選択します。2D配置メッシュからも、同じレポートを持つ3D作業コピーを検出できます。候補が複数ある場合は、使いたい3D作業コピーを選んでください。
2. **N → Fabric Pattern → 縫った結果のクロスプレビュー** を開きます。
3. 計算フレーム数、布の面密度、伸縮・曲げ剛性、最大縫合力を設定し、**縫製プレビューを作成** を押します。
4. `Fabric Sew - ...` という専用シーンへ切り替わります。**最後まで計算・録画** でクロスを1フレームずつ計算します。進捗を表示し、Escで中止できます。
5. **再生 / 一時停止** またはタイムラインで結果を確認します。録画完了後は再計算なしで任意のフレームを表示できます。`.blend` を保存すると録画も保持されます。
6. **初期状態へ戻す** は、そのプレビューの録画を削除してクロスを初期化します。条件を変更する場合は **元のシーンへ戻る** から設定して新しいプレビューを作成します。

作成したシーンだけにクロスと再生データを追加します。元のメッシュ、元のシーンの重力、フレーム範囲、他のシミュレーションのキャッシュは変更しません。各パーツの色分けは確認用で、実際の布の色ではありません。

### 計算する内容

- 三角形の角をシームに沿って分離します。同一パーツ内のダーツも、先端を残して両脚を分離します。
- 元の頂点の対応から、面を持たない辺を作成します。これがBlenderの **Sewing Springs（縫合スプリング）** になり、対応する縫い目を引き寄せます。
- 平面型紙の実寸を布の自然長に使います。**3D形状の近くに仮配置した状態から** 計算を始める方式です。平らな裁断台に置いた布を自動で持ち上げて組み立てる工程のシミュレーションではありません。
- Blender 5.1.2で静的なRest Shape Keyが自然長へ反映されない組み合わせを検出したため、初期フレームで3D配置を与え、2フレーム目から一定の平面型紙をDynamic Meshの自然長入力として渡します。頂点の運動はクロスソルバーが計算します。型紙を小さくした場合に実際のクロスも縮む回帰テストで確認しています。
- 重力の影響は初期値0です。値を上げると、固定されていない布は落下します。初期状態で固定点や人型のコリジョンは入れていません。
- 自己衝突はオプションです。縫い合わせる頂点が接近できるよう、縫い目に接する面は自己衝突から除外します。
- 布の面密度から総質量を求めて各頂点へ均等配分します。メッシュの密度差を考慮した頂点ごとの質量や、生地試験に基づく物性校正は行っていません。

縫い代の帯とダーツの余り布は計算メッシュに含めず、**縫い線上で閉じる表面** をプレビューします。ダーツの折り重なりや、ぬいぐるみの中綿による膨らみは対象外です。

### 結果の見方

録画が終わると、平均・最大の縫い目隙間と、計算後の最大伸び・縮みを表示します。型紙の許容量を超えた場合は赤いメッセージを表示します。クロスの剛性は変形への抵抗であり、型紙生成時の「伸び5％」などの上限を物理ソルバーに強制する設定ではありません。型紙生成のPASSと、クロス計算後の値は別々に確認してください。

`body_RT_sewn_preview.blend` は保存済みの `model.blend` から作成した130パーツを使い、60フレームを録画済みです。開いて再生すれば、2,262本の縫合スプリングで縫い目が閉じる結果を確認できます。平均隙間は約3.576mmから0.091mm、最大隙間は約0.729mmです。現在の初期物性では計算後の最大伸び約25.88％・縮み約10.56％があり、**元の5％許容量を超えています**。このデモは縫合と変形の確認用で、縫製可能性を保証するものではありません。詳細は `cloth_demo_report.json` に記録しています。

録画は実際の計算済み座標を1フレームごとに保存し、元のクロスオブジェクトは非表示で保持します。シェイプキーは計算結果の再生用キャッシュとして使っており、目標形状へ人工的に補間した結果ではありません。1、10、30、60フレームをファイル再読込後に照合して確認しています。

Blenderの縫合スプリングと自然長入力については、[公式マニュアルのCloth Shape](https://docs.blender.org/manual/en/5.1/physics/cloth/settings/shape.html)を参照してください。

縫い線の両側は、それぞれの許容量の範囲で伸縮するため、平面上の長さが完全に同一とは限りません。CSVに差を記録しています。対称配置や布目の最適化、パーツ数の大域的最小化も対象外です。細かい人体形状や厳しい許容量では小さなパーツが多くなることがあります。

非多様体の辺（3枚以上の面が共有する辺）や極端な面積ゼロ三角形は、修復が必要として処理を中止します。

## このフォルダーのデモ

`model.blend` の `body_RT` を、伸び5％・縮み5％、1単位＝1000mm、縫い代10mmで展開しています。結果は `body_RT_pattern_demo.blend` と `demo_output` 内の最新の **PASS** 出力です。詳細と最新出力先は `demo_result.json` を参照してください。

## 開発用の検証

```powershell
blender --background --factory-startup --python tests_blender.py
blender --background model.blend --python run_demo.py
blender --background --factory-startup --python tests_cloth.py
blender --background body_RT_pattern_demo.blend --python run_cloth_demo.py
```

`test_results.json` に検証結果を保存します。平面の実寸、オブジェクトのスケール、筒の展開、球面の自動切断、手動マーカー、布境界、重なり判定、上限時のDRAFT判定、PNGの解像度情報を検証します。
